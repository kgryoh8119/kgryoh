# スムシティ（v90）

日本の街の市長（区長・町長）になって、保育・交通・水道・財政をやりくりする 3D 都市経営シミュレーションです。
TypeScript + Three.js + Vite。サーバーなしでも遊べる単体ファイルを作れます。

遊べる街：

- **実在の街（OpenStreetMap と国土地理院の標高から作った地図）**：保土ケ谷・渋谷・横浜・梅田・天神博多・京都・吉祥寺・武蔵小杉・蒲田・宇部・城南区・時津の 12 件。各街に「実寸版」と、縮めて整理した「まちづくり版」があります。
- **架空の街「住野市」**（128 × 112 区画）：チュートリアルつき。経歴に応じて選べる地形が増え、特別シナリオの「無人島」もあります。
- 遊び方は「経営」（予算・選挙つき）のほか、自由建築・撮影・街歩き。

## 起動手順

Node.js 22 で確認しています。

```bash
npm install
npm run dev        # 開発サーバー（表示された URL を開く）
npm run build      # 型検査 → dist/ に下記の成果物を作る
npm test           # テスト（429 件（2 件スキップ、v103 時点））
npm run verify     # ブラウザでの実操作検証（要 Playwright と Chromium）
```

### 配布の成果物（`npm run build` が `dist/` に作る）

| ファイル | 大きさ | 用途 |
|---|---|---|
| `dist/index.html` ＋ `dist/maps/*.json` | 本体 約 6.7MB（gzip で約 2.1MB）＋地図 1〜2.9MB × 12 | **分割版（ウェブで公開する用）**。地図は選んだものだけを `maps/<id>.json` から取りに行く。`maps/manifest.json`（地図の一覧。小さい）だけは起動時に読む。**サーバー（http）が要る**（`file://` では地図を読めない） |
| `dist/sumucity-standalone.html` | 約 30.8MB | **単体版（オフライン・配布ファイル用）**。地図 12 件を埋め込み済み。ダブルクリックで開ける。埋め込みの地図は選んだときに初めて解析する |
| `dist/sumucity-standalone.zip` | 約 24MB | **単体版を人に配るときはこれ（v92）**。単体版の HTML に、地図データの JSON（`maps/`、ODbL の派生データベース）・`LICENSE-map-data.md`・`はじめにお読みください.txt` を添えた zip。中身は `dist/sumucity-standalone/` と同じ |
| `dist/sumucity-artifact.html` | 約 14.6MB | 公開ページ（Claude の Artifact）用。16MB の上限のため、埋め込む地図を 4 件（保土ケ谷・渋谷・横浜・梅田）に絞る（`PUB_MAPS` で変更） |
| `dist/sumucity-page.html` | 約 6.6MB | 公開ページ用の断片（地図なし） |

使い分け：ウェブに置くなら分割版（初回の通信が小さく、遊ぶ街の分だけ読む）、メールや USB で渡す・ネットがない場所で遊ぶなら単体版。分割版を `file://` で開くと、地図を読めない旨と単体版への案内が出ます。フォント（Google Fonts）は単体版でも外部から読み込むため、オフラインでは端末の日本語フォントで表示されます。計測の結果は [docs/v90-配布と性能.md](docs/v90-配布と性能.md)。

## 遊び方

1. 左の **［道］** で道路を引く（ドラッグ）。市外につながる国道まで道路がつながった区画だけが使えます。
2. **［用］** で沿道に住宅・商業などの用途を指定する（ドラッグで範囲）。建てるのは民間で、需要・水道の余力がそろうと着工します。
3. 右上の ▶ で時間を進める（1 ステップ = 1 か月）。世帯が入居し、需要が採算を超えれば店が開きます。
4. 左下の **地図レイヤー** と右の **［声］**、毎月の「今月の課題」で、どこで何が足りないかを確かめる。
5. **［施］** で市の施設を建て、施設をクリックして職員の目標や更新を指示する。**［政策］**、**［財政］**（市債）も使う。課題から対策を試算し、選んだ施策の結果は後で「予測と結果の記録」「年次報告」で見返せます。
6. **［予測］** で 12 か月・60 か月先を試算する（別スレッドで計算）。「計画案をつくる」で、建てる前に比べられます。
7. 任期（48 か月）の終わりに評価と選挙があります。落選してもサンドボックスで続けられます。

| 操作 | 内容 |
|---|---|
| 左ドラッグ | 移動（道具を選んでいるときは範囲指定） |
| 右ドラッグ | 回転 |
| ホイール | 拡大縮小 |
| W A S D・矢印 / Q E / R F | 移動 / 回転 / 拡大縮小 |
| スペース / 1 2 3 | 一時停止 / 速度 |
| Esc | 道具をやめる、地上視点・フォトモードを抜ける |
| タッチ | 1 本指で移動、2 本指で拡大縮小 |

保存は「保存・設定」から。ブラウザ内（localStorage）への保存と、テキストでの書き出し・読み込みがあります。描画の品質（低・中・高）も同じ画面で変えられます。

  economy.ts   景気・財政指標                events.ts    イベント         hazard.ts  海抜・津波・液状化
  map.ts / real.ts  地形（架空の街・実在の地図）   isle.ts   無人島（v88）
  loops.ts     3 つのゲームループ（駅前再開発・老朽インフラ・産業と暮らし）の状態と指標（v90）
  loopPolicies.ts  ループの対策として足した政策   loopHooks.ts  月次処理から呼ぶ小さな関数
  report.ts    施策の予測と結果の記録・年次報告    wire.ts  ループの指標を report.ts へつなぐ
  authority.ts 行政権限（施設ごとの市の関わり方・役）  risk.ts  災害リスクの見通し（v90）
  forecast.ts / forecast.worker.ts  予測（別スレッド）  save.ts 保存・読込

  scene.ts     シーン・カメラ・車と歩行者       models.ts / geo.ts  建物・形状ビルダー   real.ts  実在地図の描画
  roadkit.ts   路面の文字・矢印・標識（v86）     vehgen.ts  走る車・電車の生成（v86）    cargen.ts  車の生成

  infra.ts     送電線・共同溝・水管橋などの線状インフラ（v87）   rails.ts  線路   landmarks.ts  名所（GLB）

public/maps/   同梱の地図データ（12 件）
tools/         collect-map.html（地図の収集）、blender_*.py（モデルの制作）
tests/         vitest
scripts/       ブラウザでの検証・計測（v90-dist.mjs 配布の確認、v90-perf.mjs 性能の計測 ほか）

## 簡略化している点

[docs/DESIGN.md の 9 章](docs/DESIGN.md) にまとめています。金額・税率・人口の係数は全てゲーム用の仮定で、`src/sim/config.ts` で変えられます。実在の街でも、世帯数・施設の定員・予算は自治体の統計ではなくゲームの推計です（配置だけが実データ）。

## 既知の制限・未検証

- **実機の GPU での性能は未計測**です。検証環境はソフトウェア描画（SwiftShader）のみ。高品質は 1 画面あたり約 1,400 万面（影を含む）と重いので、重い端末では「保存・設定」で品質を下げてください（fps が 24 未満の状態が続くと自動で下げます）。
- **実機のスマートフォン・低性能 PC・Firefox・Safari は未確認**。確認したのは Chromium（Playwright）と、その画面幅 390px の表示まで。
- **人が通して遊んだテストは行っていません**（自動の検証と、スクリプトによる 48 か月の実操作のみ）。
- 分割版は http で配信する必要があります（`file://` では地図を読めない。その場合は単体版を使う）。
- 単体版も、フォントを外部（Google Fonts）から読み込みます。オフラインでは端末のフォントで表示されます。
- 人物の動きは Adobe Mixamo の動きから取り出した数値（`src/assets/anim.json`）を含みます。利用条件の確認は [docs/ASSETS.md](docs/ASSETS.md) を参照してください（作者の確認が必要）。
- 公開ページ（Claude の Artifact）の枠内ではファイルのダウンロードが効かないため、保存データはテキストのコピーで扱います。
- 予測は 60 か月 × 3 本で数秒かかります（計算中も画面は動きます）。
- 古い版の既知の制限（小さな施設の扱い、斜面、民間建物の撤去など）は [docs/DESIGN.md](docs/DESIGN.md) と各変更記録にあります。
