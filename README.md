# スムシティ（Phase 1）

日本の市長として街を経営する 3D 街づくりシミュレーションの初版です。
今回の範囲は **架空の市「住野市」の市長モード**、シナリオは「駅前開発で子育て世帯が増える郊外都市」です。

- 設計資料：[docs/DESIGN.md](docs/DESIGN.md)
- 検証結果：[docs/VERIFICATION.md](docs/VERIFICATION.md)
- アセット・ライセンス：[docs/ASSETS.md](docs/ASSETS.md)
- 地図の選択・追加（保土ケ谷ほか 5 地域）と実在地図での置きやすさ：[docs/MAPS.md](docs/MAPS.md)
- 実在都市版（保土ケ谷）の中身と限界：[docs/REAL_HODOGAYA.md](docs/REAL_HODOGAYA.md)

## 起動手順

Node.js 22 で確認しています。

```bash
npm install
npm run dev        # 開発サーバー（表示された URL を開く）
npm run build      # 型検査 → dist/index.html と dist/maps/（地図データ）、公開ページ用の断片、地図を埋め込んだ単体版 dist/sumucity-standalone.html
npm test           # 因果テスト（28 件）
npm run verify     # ブラウザでの実操作検証（要 Playwright と Chromium。scripts/shot.mjs のパスは環境に合わせる）
```

`dist/index.html` は 1 ファイルで完結しており、ダブルクリックで開けます（サーバー不要）。

## 遊び方

1. 左の **［道］** で道路を引く（ドラッグ）。市外につながる国道まで道路がつながった区画だけが使えます。
2. **［用］** で沿道に住宅・商業の用途を指定する（ドラッグで範囲）。建てるのは民間で、需要・水道の余力がそろうと着工します。
3. 右上の ▶ で時間を進める（1 ステップ = 1 か月）。世帯が入居し、需要が採算を超えれば店が開きます。
4. 左下の **地図レイヤー** と右の **［声］** で、どこで何が足りないかを確かめる。
5. **［施］** で市の施設を建て、施設をクリックして職員の目標や更新を指示する。**［政策］**、**［財政］**（市債）も使います。
6. **［予測］** で 12 か月・60 か月先を試算する。「計画案をつくる」で、建てる前に比べられます。
7. 任期（48 か月、体験版 24 か月）の終わりに評価と選挙があります。落選してもサンドボックスで続けられます。

| 操作 | 内容 |
|---|---|
| 左ドラッグ | 移動（道具を選んでいるときは範囲指定） |
| 右ドラッグ | 回転 |
| ホイール | 拡大縮小 |
| W A S D・矢印 / Q E / R F | 移動 / 回転 / 拡大縮小 |
| スペース / 1 2 3 | 一時停止 / 速度 |
| Esc | 道具をやめる、地上視点・フォトモードを抜ける |
| タッチ | 1 本指で移動、2 本指で拡大縮小 |

保存は「保存・設定」から。ブラウザ内（localStorage）への保存と、テキストでの書き出し・読み込みがあります。

## 実装済み（Phase 1）

- 3D マップ（地形、道路、歩道、交差点、区画）、昼夜・夕景・夜の窓と街灯、俯瞰カメラ、地上視点、フォトモード
- 道路の建設・拡幅・補修・撤去、道路ネットワークと市外への接続判定
- 住宅 3 種・商業の用途指定と、需要に応じた民間の着工・開業・閉店・退去
- 市の施設 6 種（保育園、小学校、公園、消防署、水道施設、ごみ収集拠点）の建設・休止・更新・撤去
- 職員の目標と採用、実効容量、維持費、老朽化、更新
- 月次の人口・需要・雇用・交通・財政・満足度（世帯類型別・地区別）
- 政策 5 種、イベント 10 種、原因つきの住民の声
- 将来予測（12・60 か月、楽観／基準／慎重、現在のままと計画案の比較）、統計、地図レイヤー 4 種
- 一時停止・3 段階の速度、期末評価と簡略選挙、落選後のサンドボックス
- 保存・読込、新規開始、チュートリアル（11 手順）

## 簡略化している点

[docs/DESIGN.md の 9 章](docs/DESIGN.md) にまとめています。主なもの：道路は直線の格子のみ、上下水道とごみは拠点の能力だけ、
税と移転収入はゲーム独自の近似、選挙は得票率の計算のみ、駅は市外への接続拠点としてのみ扱う。
金額・税率・人口の係数は全てゲーム用の仮定で、`src/sim/config.ts` で変えられます。

## 既知の制限

- 実機の GPU での性能は未計測です（検証環境はソフトウェア描画のみ）。重い場合は「保存・設定」で品質を下げてください。
- 動作確認は Chromium 系のみ。Firefox・Safari、実機のタッチ操作は未確認です。スマートフォンは「崩れずに表示できる」までで、操作性は次段階です。
- 交番・診療所は景観と権限の説明用で、計算には影響しません。
- 小学校の増築はできません（新設のみ）。人口が増えると過密になりやすいです。
- 民間の建物は経営モードでは撤去できません（区画整理や補償は未実装）。
- 斜面は緩い丘までで、急な斜面と水面・保全林には建てられません。
- 予測は 60 か月 × 3 本で数秒かかります（計算中も画面は動きます）。
- 公開ページ（Claude の Artifact）の枠内ではファイルのダウンロードが効かないため、保存データはテキストのコピー、写真は画像の長押し・右クリックで保存します。

## ソースの構成

```
src/sim/      ゲーム状態と計算（DOM・Three.js に依存しない）
  config.ts   係数、施設定義、政策、公約        events.ts  イベント定義と効果
  core.ts     再計算（接続・容量・需要・交通・満足度・声）
  step.ts     月次処理、財政、選挙             actions.ts 操作（dispatch）
  scenario.ts 初期シナリオ   forecast.ts 予測   save.ts 保存・読込   map.ts 地形
src/render/   3D 表示（geo.ts 形状ビルダー、models.ts 建物モデル、scene.ts シーン・カメラ・車と歩行者）
src/ui/       画面（ui.ts、chart.ts、style.css）
src/game.ts   時間の進行、計画案、保存
tests/        因果テスト
scripts/      ブラウザ検証・バランス確認
```
