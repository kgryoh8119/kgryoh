# v5：暮らしの観点・公共施設・公約と選挙・税・誘致・できごと

## 暮らしの観点（満足度 14 項目）
住宅負担・通勤・保育・学校・公園・買物・消防防災・ライフライン（電力・水道・下水・ガス・ごみ）・雇用・医療・治安・環境（空気）・文化スポーツ・福祉。
世帯類型ごとに重みが違う（`SAT_W`）。住宅ごとの水準は `b.sv`（12 項目、`SV_NAMES`）。

- 電力・下水・ガス・ごみ：需要と能力。市外からの供給（`s.base`、最初の再計算で需要×1.3）に施設の分を足す。電力・下水の余力がないと民間の住宅が着工しない。
- 空気：道路の交通量と工場・清掃工場などの排出をぼかして広げ、公園・緑で減らす。
- 浸水：水面から 2 区画以内で高さが 3m 以内の区画。雨水調整池で地区の被害が半分。
- 地図レイヤー：満足度・保育・教育・医療・福祉・治安・防災・空気・文化・ライフライン（2 段目「暮らし」）。

## 施設（建設・要望・誘致できるもの 43 種）
分類：子育て／教育・文化／公園・スポーツ／消防・防災・治安／水道・電気・ガス・ごみ／医療・福祉／ランドマーク／企業誘致。

- 市が建てる（`build: 'city'`）：小規模保育所・市立保育園・大型保育園、小・中学校、図書館分館・中央図書館、街区・近隣・総合公園、体育館、消防出張所・消防署・消防本部、備蓄倉庫、雨水調整池、配水池・浄水場・大規模浄水場、下水処理場（2 種）、ごみ収集拠点・清掃工場（ごみ発電）、メガソーラー、市民病院、地域ケアプラザ、文化ホール・美術館・展望タワー・スタジアム。
- 要望（`request`。県・事業者が建て、市は用地と負担金）：県立高校、交番・警察署、変電所、ガス整圧所、特別養護老人ホーム。
- 誘致（`invite`。企業が建てる。条件と税で見込みが変わり、失敗もある）：診療所、オフィス、工場、物流センター、データセンター、ホテル、テーマパーク（知名度 30 以上）。
- 増築：多くの市の施設はレベル 3 まで（能力 100/135/170%、維持費 100/125/150%、費用は建設費の半分）。

## 公約・ビジョン・選挙
- 任期の初めに公約を 3 つ選ぶ（15 種、難しさ ★1〜3）。目標値は選んだ時の街の状態から決まる。選んだ時点で達成済みのものは「維持」として ★1 扱い。
- ビジョン（6 種、最初の任期で 1 つ）：3 期かけて目指す街の姿。進み具合が得票に少し効く。
- 得票の見込み = 50 + 暮らしの満足 + 公約 + 支持率 + 収支 + 一時借入 + 対立候補 + ビジョン。当日は乱数（3 つの一様乱数の和）でぶれる。［任期］タブに当選確率と内訳。
- 支持率：満足・税・できごとで毎月動く。

## 税
住民税・固定資産税・法人の税を標準の 85〜115%（半年に 1 回）。宿泊税（ホテルがあるとき）。上げると支持率が下がり転出が増え、法人の税を下げると誘致の見込みが上がる。

## 市長の取り組み・隣の市町
視察（子育て・環境・観光）、企業誘致フェア、姉妹都市、市民まつり、対話集会、防災訓練、防犯パトロール、隣町との広域連携。
隣の市町 3 つ（架空）。住みやすさと税を比べて転入・転出が動く。

## できごと（34 種）
地震・水害・大雪・猛暑・感染症・大火事・交通事故・不祥事・水道管の破裂・停電・空き巣、海外の戦争（物価・資材高・避難民）・不況・好景気・国の補助、企業・テーマパーク・ホテルの進出の打診、プロスポーツチーム、表彰、視察の受け入れ、隣町の大型店・合併の打診・応援など。
前のできごとから 2 か月は、災害など突然起きるもの以外は起きない。

## 住宅の用地買収
どの地図でも、住宅を選んで［用地を買収して撤去］。土地代と補償（空き家なら安い）を払い、住んでいる世帯は転居、支持率が少し下がる。跡地は用途の指定なしの空き地。

## 調整（ゲーム用の仮定）
得票 50% になる満足度：架空の街 0.70、まちづくり版 0.655、実寸版 0.615。金額・定員・効果はすべてゲーム用の仮定で、実際の制度や統計ではない。
