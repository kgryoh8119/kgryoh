# スムシティ 保土ケ谷（実在都市版・試作）

架空の「住野市」と同じゲームの仕組みを、実在の地図に載せた版です。
範囲は **保土ケ谷区を中心に、西谷・上星川・和田町・星川・天王町・保土ケ谷駅のあたり**。
プレイヤーは **横浜市長**として、この範囲を一つの街として運営します（案 A。区の境界は使っていません）。

## 実在のもの・推計のもの

**地図どおり（OpenStreetMap・国土地理院）**

- 道路・鉄道・川の線、地形の起伏
- 建物の位置と種類（OSM に登録されている 53,286 棟）
- 駅 8、小学校 22、消防署・出張所 8、保育園 30（名前が「横浜市…」で始まる 10 園を市立、ほかを私立とした）、スーパー 22、交番 9、診療所 32、公園 159 の名前と位置

**ゲームの推計・設定（実際の値ではありません）**

- 世帯数：区画の中の建物から推計（戸建て 1 戸、集合住宅は階数 × 2〜5 戸 など）。約 5.97 万戸、人口は約 12 万人になります
- 世帯構成、施設の定員・職員・老朽度、浄水場の能力、予算・税収・建設費（架空の街の値を人口に合わせて約 26 倍）
- 西谷浄水場の位置：OSM に施設として登録がなく、土地利用の面から推定しました
- 公約の目標：待機児童 100 人以下、最大混雑率 150% 以下（12 万人規模に合わせて変更）

## 簡略化していること

- 計算上の道路は 30m 区画単位です。生活道路より細い道（住宅地の路地）は**描くだけ**で、計算には入れていません（切れ目は取り込み時に細い道でつないだ）。
- 道路の種類は 国道（国の管理・市は広げられない）／幹線／生活道路 の 3 種類です。自動車専用道路（保土ケ谷バイパスなど）と鉄道は描くだけです。
- 区画の中の店・事務所・工場、建物データのない市街地は、計算上は「住宅のない区画」です。見た目は OSM の建物を描き、OSM に建物が足りない区画は**推計の戸数まで家並みを補って描いています**（補った家は人口に数えません）。
- 学校・浄水場などの建物は、ゲームの標準の形で描きます（実際の外観ではありません）。
- 市の施設を建てると、その区画の既存の家並みは消えます（用地を確保した扱い）。

## 検証したこと（この環境：GPU なしの Chromium／SwiftShader）

| 確認 | 結果 |
|---|---|
| 計算のテスト（架空 110 件、実在 2 件） | すべて合格 |
| 起動 | 約 9〜11 秒（GPU なし。街の描画の組み立ては 2.3〜3.1 秒） |
| 1 か月の計算 | 約 0.25 秒（6 か月で 1.5 秒） |
| 予測（3 通り × 60 か月） | 約 27〜28 秒。別スレッド 3 本で並列に計算し、画面は止まりません |
| 市立保育園の建設（画面の操作）・案内の進行 | 動作 |
| できごと（渋滞の陳情）の発生と選択 | 動作。市全体の対策の費用は街の大きさに合わせて増額 |
| 保存 → 読み込み | 一致（保存データ約 3.3MB、ブラウザ保存も Chromium で成功） |
| 地上視点・俯瞰・遠景、スマートフォン幅（390px） | 表示を確認 |
| 描画の頂点データ | 約 114MB（法線を持たず色を 1 バイトにする工夫で、当初の約 3 分の 1） |
| ページのエラー | なし（外部フォントの読み込み失敗のみ。この環境の通信制限） |

**確認できていないこと**

- 実機（GPU あり）のフレームレート。この環境では GPU がないため 2〜6fps しか出ず、品質の自動調整が働きます
- iPhone の Safari：ブラウザ保存の容量（約 3.3MB の保存データが入らない場合は「ファイル保存」を案内します）、メモリ
- 世帯数・待機児童などが実際の保土ケ谷区の統計とどれくらい合うか（合わせ込みはしていません）

## 何もしない場合の見通し（予測タブの基準ケース、60 か月）

人口 約 12.0 万 → 11.7 万、保育需要 2,585 → 約 3,900 人、待機 916 → 約 1,600 人、最大混雑率 213% → 約 170%。
保育士の採用上限を街の大きさに合わせたので、既存の園の職員は維持されます。待機を減らすには保育園の新設が必要です。

## 地図を作り直すには

1. `tools/collect-map.html` をブラウザで開き、「保土ケ谷」を選んで「集める」→ `hodogaya-data.json` を保存
2. `data/hodogaya-data.json` に置いて `node scripts/import-map.ts hodogaya` → `public/maps/hodogaya.json`
3. `npm run build`（地図は開始時に選びます。詳しくは [MAPS.md](MAPS.md)）
