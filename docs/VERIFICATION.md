## 3. 性能の記録

計測環境：クラウド上の Linux コンテナ（CPU 2 コア、GPU なし）。Chromium 141 ヘッドレス、描画は SwiftShader（ソフトウェア）。
**GPU のある端末での値ではありません。** 実機の性能は保証しません。

| 項目 | 値 |
|---|---|
| 解像度 | 1440×900、devicePixelRatio 1 |
| 建物数 | 315（開始時）〜343 |
| 描画する車・歩行者 | 118 台・155 人（高品質）、41 台・54 人（低品質） |
| 1 フレームの三角形数 | 約 50〜79 万（影の描画ぶんを含む、高品質）、約 35 万（低品質・影なし） |
| 描画回数 | 約 70〜160 回/フレーム |
| フレームレート | 2〜4 fps（高品質）、5 fps（低品質）。**ソフトウェア描画での値** |
| 月次計算 | ブラウザ内で 1 か月あたり約 4.7 ms、Node では 8 ms 前後（暖機後） |
| 予測（60 か月 × 3 本） | 約 2.1 秒 |
| 街のメッシュ生成 | 起動時の全体生成 約 0.6 秒、その後は変わった 6×6 区画だけ（1 回 約 30 ms） |
| 保存データ | 約 155 KB、書き出し約 10 ms |
| 配布物 | `dist/index.html` 約 730 KB（Three.js を同梱） |

低品質設定（影なし・解像度等倍・車と歩行者を約 1/3）でも、文字と施設の看板・形が読めることをスクリーンショットで確認しました。
