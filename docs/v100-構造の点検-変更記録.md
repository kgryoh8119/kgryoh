# v100 構造の点検 変更記録

作者の指摘：「道路がめちゃくちゃ浮いてるけど、構造上大丈夫？途中に支柱がないの変じゃない？他にも物理的にあり得ないものは、なしにしてね。」

## 点検の方法

`scripts/v100-structure.ts`（`npx esbuild scripts/v100-structure.ts --bundle --platform=node --format=esm --outfile=/tmp/s.mjs --loader:.json=text && node /tmp/s.mjs`、`BEFORE=1` で v99 の規則）。
8 地形のはじめの街と、保土ケ谷（まちづくり版）で、桁の区間と支えの位置を描画と同じ規則で集め、支えどうしの間隔（径間）の最大値を出す。
立体交差はどの街にも元からないので、同じ場面（交差点が続く幹線に立体交差を 3 つ置き 1 本の高架にまとめる：交差点が 4 つ連続する区間を含む）を空き地に作って数える（保土ケ谷は空き地がなく作れない）。
立体交差は `flySupports`（sim/grade.ts）、鉄道は `railPiers`（render/rails.ts）を描画と点検が共有する。道路橋は scene.ts の `computeDecks`・`drawDeck` の規則を台本に写したもの。

目安：道路・鉄道の高架の桁は 1 径間 30〜40m（長くても 50〜60m）、歩道橋 20〜30m。

## 直したもの

1. **立体交差の高架**（`sim/grade.ts` `flySupports`、`render/scene.ts` `drawFlyovers`）
   - v95 の「中央分離帯の橋脚は交差点・横断歩道・脇道の区画に立てない」は保ったまま、支えの間が 40m を超える所に**門形の橋脚**を足す。
     柱は交差点の区画の角：下の幹線の歩道の外（中心から 11m）、交わる道路の歩道の外（交差点の中心から交わる道路の半幅＋歩道＋1.4m）。
     梁は桁と同じ高さに組み込み、側道の上も桁下 4.5m 以上を残す。交差点が続いて分離帯が無い所も、交差点ごとに門形で 40m 以下。
   - 坂の低い所（桁下 2m 未満）は、薄い桁が地面すれすれに浮いていたのを、**擁壁で囲んだ盛土**にして、端に橋台の壁を描く。
   - 交差点が 4 つ続く場面で、最大径間 150m → 39m。
2. **鉄道の高架・モノレール・新交通**（`render/rails.ts` `railPiers`）
   - 橋脚が道路を横切る所（車線・歩道の帯）に立っていた（保土ケ谷で 29 本。v99 の「門形」も柱が横切る道路の上だった）。
     横切る帯には立てず、帯の手前（先読み）か渡り終えた所に立てる。道路に沿って重なる所だけ、柱を道路の歩道の外に立てる門形にする。
   - その代わり、道路を斜めに横切る所などで径間が最大 48m になる（目安の「長くても 50〜60m」の内）。
3. **道路橋**（`render/scene.ts` `drawDeck`）
   - 谷を渡る高い橋の橋脚が 1 区画おき（60m）だったのを区画ごと（30m）に（はじめの街には該当なし。山の地形で街を広げると出る）。
   - 掘った水路の上の橋は、水路の中ではなく両岸（区画の中心から ±13m）に橋脚を立てる。
   - 桁下が水面に近い低い橋では鋼の主桁（路面の 2〜3.4m 下）が水に浸かっていた（inland 24 区画など）。主桁を下げない床版橋にする。
4. **斜面の建物**（`render/scene.ts` `drawBuilding0`・`lotLow`）：建物は敷地のいちばん高い所に置くので、低い側で浮いていた。
   敷地の高低差が 0.35m を超える所は、敷地の低い所から土台まで石積みの擁壁（造成した敷地）を描く（住野市で最大 2.8m）。

## 残ったもの・見ていないもの

- 鉄道の径間は道路を斜めに横切る所で最大 48m（40m は超える）。門形で道路を斜めにまたぐ形は作っていない。
- 大河を長い径間で渡るトラス・アーチの道路橋は作っていない（川の中に 30m おきに橋脚を立てる形で目安内）。
- 木・電柱・街灯・信号・標識の浮き・埋まり、建物どうし・道路と建物・線路と建物の重なり、車・人の空中・地中は、撮った近景（立体交差・坂・斜面の家・保土ケ谷の高架）で目立つものは見つからなかったが、全数は点検していない。
- 保土ケ谷の撮影では、直す前も後も THREE の「position に NaN」の警告が出る（v100 で増えたものではない。原因は未調査）。
- 川の橋の画像（before/after-bridge）は撮ったが見ておらず、記録には入れていない。
- 道路橋の点検は scene.ts の規則を台本に写したもの（描画と関数を共有していない）。
- 保土ケ谷には空き地がなく、立体交差の場面は作れなかった。
