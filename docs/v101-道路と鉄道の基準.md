# v101：この作品で使う道路と鉄道の基準（日本）

作者の指摘（v100 の交差点が続く立体交差の近景）「シャドウと歩道の幅ってこんな感じで大丈夫なん？道路交通法や運送法、鉄道法なども加味して」を受けて、
描画で守る基準を整理した。**手元の知識による整理で、条文番号・数値は「目安・相場」**。法令名は出典として添える。確かめられていないものは「未確認」と書いた。
ゲームの 1 区画は 30m 四方（`TILE = 30`）。道路の等級は 1：生活道路（車道 5m）、2：2 車線（車道 10m）、3：幹線 4 車線（車道 15m）、2＋立体交差の前後（6 車線の幅、車道 15m）。

## 1. 道路構造令（政令。道路法に基づく道路の構造の一般的技術的基準）

| 項目 | 基準の要点（目安） | この作品での扱い（v101） |
|---|---|---|
| 車線の幅 | 第 1〜4 種の級ごとに 3.5m・3.25m・3.0m（第 4 種＝都市部の一般道は 3.0〜3.25m が多い） | 2 車線：片側 3.25m＋路肩、4 車線：3.25〜3.5m（車線境界線は中心から 3.75m） |
| 路肩 | 左側 0.5〜1.25m 程度（歩道のある道は 0.5m まで縮められる） | 外側線は縁石の 0.8m 内（幹線）・0.3m 内（2 車線） |
| 歩道の幅 | **歩行者の交通量が多い道路は 3.5m 以上、その他は 2m 以上**（自転車歩行者道は 4m／3m 以上）。並木を植えるときはさらに 1.5m 程度足す | **等級ごとに一定**：2 車線 3.0m、幹線・立体交差の前後 3.5m（区画の境で段違いにしない。`roadbase.ts` の `walkW`） |
| 自転車道 | 幅 2m 以上（やむを得ない場合 1.5m）。自転車通行帯（区画線による）は 1.5m 程度が目安（国交省・警察庁の「安全で快適な自転車利用環境創出ガイドライン」） | 2 車線の道の青い自転車レーンは車道の左端 0.95m（ナビマークの扱い。専用の自転車道は描かない） |
| 中央帯（中央分離帯） | 4 車線以上の第 1〜3 種などで設ける。幅は 1〜3m 程度が目安（側帯を含む） | 幹線は黄の実線か白の 2 本線。立体交差の高架の下は分離帯（v95） |
| 植樹帯 | 幅 1.5m が標準（第 4 種第 1 級などで設ける） | 幹線の歩道の車道側の生け垣（0.75m の箱。歩道の幅の内側） |
| 交差点の隅切り | 道路構造令には数値が無い。都市計画・開発許可の運用で、歩道のある交差点の縁石の曲線半径は相場 5〜10m（幹線どうし）、歩道の無い生活道路の敷地の隅切りは 2〜3m の二等辺（建築基準法・各地の条例） | 縁石の円弧の半径 `CORNER_R = 3m`（30m の区画に収めるため小さめ）。**歩道の外の端も同じ中心の円弧（半径 3m＋歩道の幅）で回し、角でも歩道の幅を一定**にする（v101） |
| 縦断勾配 | 設計速度ごとの上限（60km/h で 5%、40km/h で 7% 程度。特例で +1〜2%） | 立体交差の坂（`grade.ts`）は 4 区画で 7.5m ほど上る（約 6%）。v101 では変えない |

## 2. 道路交通法と「道路標識、区画線及び道路標示に関する命令」（標識令）

| 項目 | 基準の要点（目安） | この作品での扱い（v101） |
|---|---|---|
| 横断歩道（標示） | 縞の幅 **45cm**、間隔 **45〜50cm**、横断歩道の幅（歩行者の歩く向きと直角の長さ）は **4m 以上が原則**（やむを得ない場合 3m まで縮められる）。縞は車の進む向きに平行 | 縞 0.45m・間隔 0.45m、幅は幹線 4m・2 車線 4m・生活道路 3m。**交差点の 4 辺の歩道の切り下げどうしを結ぶ位置**に置き、交差点の中・互いに重ならない（`crosswalkLayout`） |
| 停止線 | 横断歩道の手前 **1〜2m**（標示の設置基準の運用で 2m が多い）。幅 0.3〜0.45m の白の実線 | 横断歩道の外の端から 2m 手前に 0.45m（近づく車線の側だけ） |
| 交差点の中 | 原則として標示を引かない（車線の区画線・中央線は交差点の手前で止める）。必要な所だけ「右折の方法」の導流線（点線）・右折待ちの位置 | 中央線・車線境界線・外側線は交差点の手前（停止線）までで止める。交差点の中は無地（カラー舗装だけ） |
| 導流帯（ゼブラ） | 車の通行を誘導する白の斜めの縞（標識令の区画線「導流帯」）。右折車線をつくる所の手前、車道が絞られる所、分合流の所に置く | **右折車線が始まる所の手前**（幹線が交差点に近づく区画）だけ。交差点が隣り合う 30m の間（右折車線を作る長さが無い）には置かない |
| 駐停車禁止の範囲（道交法 44 条） | 交差点とその側端から 5m 以内、横断歩道・自転車横断帯とその前後 5m 以内、踏切とその前後 10m 以内、バス停の標示柱から 10m 以内（運行時間中）、安全地帯の左側と前後 10m | バス停・荷さばきの停車位置をこの範囲の外に置く（§4） |
| 信号機の設置 | 都道府県公安委員会が設置（道交法 4 条）。警察庁の「信号機設置の指針」（平成 28 年ごろ。数値は相場）：主道路の交通量がピーク時 300 台/時 以上程度、**隣の信号機との距離が原則 150m 以上**（系統制御する場合を除く）、歩行者の横断需要、事故の多さ。生活道路どうし・生活道路と幹線の交差点は、一時停止（「止まれ」の標識＋停止線）で対応するのが普通 | **信号機は幹線（2 車線以上）どうしが交わる交差点だけ**。生活道路との交差点は生活道路の側に「止まれ」。さらに、信号のある交差点が 1 区画（30m）おきに並ぶ所は、交わる道が狭い方を間引いて一時停止にする（§5） |
| 一時停止 | 「止まれ」の標識（規制標識 330）と停止線、路面の「止まれ」（指示標示）。停止線は交差する道の端の手前 | 生活道路の側の停止線は、交わる道の縁石の円弧の外 0.5m |

## 3. 鉄道（鉄道に関する技術上の基準を定める省令・解釈基準、踏切道改良促進法）

| 項目 | 基準の要点（目安） | この作品での扱い（v101 で確かめた） |
|---|---|---|
| ホームの幅（省令の解釈基準） | 島式（両側使用）は中央部 3m 以上・端部 2m 以上、相対式（片側使用）は中央部 2m 以上・端部 1.5m 以上。旅客の多い駅はさらに広く。ホームの縁から 1m 程度は点字ブロックの内側 | `rails.ts` のホーム：v101 で幅を確かめた（§6） |
| 曲線半径 | 普通鉄道の本線は 160m 以上（新幹線は 400m 以上、高速区間は 4000m 程度）。駅の中はできるだけ直線 | 線路の曲線（`rails.ts`）は区画の角を 1〜2 区画の円弧で回す（30〜60m）。路面電車・入換えの扱いで、本線としては急。大きな作り替えになるので v101 では変えない（未対応として記録） |
| 踏切の構造 | 踏切保安設備（第 1 種：遮断機と警報機、第 3 種：警報機のみ、第 4 種：無し）。新設は原則として立体交差（道路と鉄道の交差は立体が原則：道路法 31 条・鉄道の解釈基準）。踏切の手前に停止線、「踏切あり」の警戒標識（210）、踏切の中は外側線（黄色の線は事業者の運用） | 第 1 種（遮断機＋警報機＋×印）。停止線は踏切の手前（遮断機の手前 2m 程度）、「踏切あり」の標識。v101 で位置を確かめた |
| 踏切道改良促進法 | 改良すべき踏切を国が指定し、立体交差化・構造改良・歩行者対策を進める（踏切を減らす考え方）。道路交通法 33 条：踏切の直前で一時停止 | ゲームの規則（`grade.ts`）では幹線と線路の交差は陸橋・高架になる。車は遮断機が下りていれば手前で待つ（v86） |

## 4. 道路運送法・バスの停留所

| 項目 | 基準の要点（目安） | この作品での扱い |
|---|---|---|
| 道路運送法 | 一般乗合旅客自動車運送事業（路線バス）の許可、停留所の位置・名称を含む事業計画の認可・届出（道路運送法 4 条・15 条など） | ゲームでは「バス停」を道路の区画に置く（sim の配置は変えない） |
| 停留所の位置 | 停留所の標示柱から 10m 以内は他の車の駐停車禁止（道交法 44 条）。運用の目安として、**交差点・横断歩道から 30m 程度離す**、交差点の向こう側（通り過ぎた側）に置く、横断歩道の手前に止まったバスの陰から人が飛び出さないようにする（国交省・警察の運用。数値は未確認の相場） | **交差点の区画にバス停の待合所を置かない**（歩道の角に重なっていた）。交差点の隣の区画では、交差点から遠い側の端に寄せる（v101） |

## 5. 信号の置き方（v86・v89 と v101）

- v86（車・人の信号停止）と v89（灯の切り替え）は、どちらも `scene.ts` の `signals()` の答え（同じ格子）を使う。v101 ではこの 1 か所だけを変え、ずれないようにした。
- v101 の条件（`sigPlan`、`roadbase.ts` の純粋な関数）：
  1. 3 方向以上に道路がつながる区画で、**つながる道（自分を含む）のうち 2 車線以上の道が 3 本以上**（＝幹線どうしの十字路か、幹線の T 字で突き当たる道も幹線）。生活道路と幹線の交差点は信号なし（生活道路の側に止まれ）。
  2. 信号の交差点どうしが **150m（5 区画）未満**で同じ通りに並ぶときは、交わる道が狭い方（同じなら番号の小さい方を残す）を間引いて、一時停止の交差点にする。
- 一時停止の交差点では、狭い方の道（同じ幅なら決まった片方）に「止まれ」の停止線・路面の文字・標識を置く。

## 6. 影（シャドウ）の設定の目安（描画の内部の基準）

- 太陽光の影は 1 枚のシャドウマップ（PCF）。範囲は注視点の周り（±200〜900m）、細かさは品質ごとに 1024（中）・2048（高）・4096（高・大画面）。
- bias（深さのずれ）は、影の深さの範囲（near〜far）の長さに比例して効く。far を太陽までの距離に合わせて詰め、bias を小さくすると、細い柱・低い縁石の影が足元から離れる（ピーターパン）・消えるのを防げる。normalBias は影の画素の大きさの半分程度が目安。
