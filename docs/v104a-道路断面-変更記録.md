# v104a 道路の断面（歩道と路側帯のつながり）と、草地に立つ人 — 変更記録

## きっかけ

朝 8 時の住野駅前を真上から見ると、こう見えていた。

- 駅前の通り（生活道路）には段差のある歩道がなく、人は白線の外の路側帯を歩いている。
- その通りが交差点の区画に入る所で、急に灰色の歩道の平板が角に現れ、路側帯を横切るように直角の縁が付いている。路側帯を歩いてきた人が、歩道の平板の横腹へ突き当たるように見える。
- 道路の横の芝生・草地に、人が列になって立っている。

道路構造令では、道の断面（車道・歩道・路側帯の並び）は続けて同じにし、幅や形が変わる所はすりつけて変える。ゲームの絵もそれに合わせた。

画像は `docs/shots/v104a/`（`-before` が直す前、`-after` が直した後）。

## 原因

### 1. 交差点の区画と、となりの区画で、断面の決め方が違っていた

- 区画ごとの路面は `src/render/roadbase.ts` の `roadBase` が描く。段差のある歩道にするか、路側帯だけにするかは、`scene.ts` で区画ごとに決めていた（`kerbless = tR === 1 && …`）。
- 交差点の区画の等級 `tR` は「つながる道の広い方」。駅前の生活道路が二車線の道と T 字に交わる区画では `tR = 2` になり、交差点の区画だけが「歩道あり」になっていた。となりの生活道路の区画は「路側帯」。
- 交差点の区画では、生活道路の腕の歩道が区画の半分（15m）をかけて少しずつ低くなるだけで、平板の色と縁は区画の境まで続いていた。そのため、区画の境で、路側帯（アスファルトの色・路面の高さ）と歩道の平板（明るい灰色）が直角にぶつかっていた。
- 外側線も交差点の区画の等級で引いていたので、二車線の道と交わる交差点では、生活道路の腕の外側線が 0.65m 内側へずれていた。

### 2. 人が草地を横切って建物に出入りしていた

- 道路の区画は 1 辺 30m で、車道と歩道（路側帯）の外は草地。たとえば生活道路は両側に 10m ずつ草地が残る。
- 建物に入る人・出てくる人は、歩道の中ほどから真横へ区画の境まで歩いていた（`scene.ts` の `enter`・`exit`）。その途中はずっと草地だった。
- 住民は行き先の区画に着くと、そのとき歩いていた側へ入っていた。駅前では、駅は北側なのに、南側の歩道を歩いてきた人は南の草地へ列になって入っていった（直す前の真上の画の、道から下へ伸びる 2 本の人の列）。
- 会社・工場など、入口の決まりに入っていない建物の前でも、同じように草地へ入っていた。

### 3. 駅のまわりの歩道に並ぶ人の一部が、T 字の向こうの草地に立っていた

- 駅のまわりの歩道に並べる人（`plazaPts` の `st`）は、区画の端から端まで並べていた。T 字の突き当たり（腕の無い側）では、その位置は草地になる。
- 駅前広場・入場規制の列の立ち位置も、道路の区画に掛かる所を確かめていなかった。

## 直したこと

### 道路の断面（`src/render/roadbase.ts`・`src/render/roadkit.ts`・`src/render/scene.ts`）

1. **歩道を付ける区画を 1 つの決まりで決める（`kerbPlan`）。** 描画とテストで同じ関数を使う。
   - 二車線以上の道（交差点はつながる道の広い方の等級）、石畳・並木道：歩道あり。
   - 生活道路のうち、**駅のまわり 3 区画**と**学校・保育所の敷地に接する区画**：人が多いので歩道あり。幅は v101 の `walkW`（幹線 3.5m・二車線 3.0m・生活道路 2.5m）のまま。
   - それ以外の生活道路：路側帯（学校のまわり 3 区画は今までどおり緑の路側帯）。
   - 円弧の曲がり角は、両側の区画がどちらも歩道ありのときだけ歩道あり。
   - 駅前の通り（車道 5m の生活道路）は、直線の区画にも交差点にも同じ決まりで歩道を付けた。区画ごとに違う決まりにはしていない。

2. **腕ごとの断面（`kerbArm`）。** 区画の境の腕は、両側の区画がどちらも歩道ありのときだけ歩道あり。だから区画の境の両側で断面が必ず同じになる。

3. **歩道が路側帯に変わる所は、すりつけて終える。**
   - 歩道のある道と路側帯だけの道の角：縁石は隅切りの円弧（半径 4m）を回り、横断歩道の所に切り下げと点字ブロックを付け、その先 6m（`TAPER_L`）で縁石の線が歩道の外の端へ斜めに寄りながら低くなって終わる。その先は路側帯で、外側線がそのまま続く。
   - 直線の区画で歩道が終わる所（駅のまわりの端など）：区画の中ほどの 6m で同じようにすりつける。
   - v103 までの「歩道の平板が区画の境まで続き、路側帯へ突き出す」形は無くなった。

4. **外側線を腕ごとに引く。** 腕の先の道の等級と歩道の有無で決める。生活道路の外側線は、歩道の有無にかかわらず車道の端から 0.3m（前は路側帯の道だけ 0.15m）。歩道の始まる所・終わる所で線が段違いにならない。

### 草地に立つ人（`src/render/frontage.ts`（新）・`src/render/scene.ts`）

1. **建物の入口の通路。** 直線の区画で、横の敷地に建物があれば、区画の中ほどに、歩道の外の端から区画の境（敷地の入口）まで舗装した通路を描く（幅 3m、店・駅など人の多い入口は 4m）。段差のある歩道の区画では歩道の高さ、路側帯の区画では路面の高さ。1 か所に 2〜4 枚の面なので重さはほとんど変わらない。
2. **出入りは通路だけを通る。** 人は区画の中ほどの通路の所（中心から 1.2m。電柱を避ける）まで歩いてから入る。出てくる人も通路から出てくる。
3. **入口の無い側へは入らない。**
   - 反対側に入口があるとき：生活道路（中央線の無い道）は道を渡って向かいの入口へ入る。二車線以上の道は渡らずに、着いたことにする（横断歩道でない所で広い道を渡らない）。
   - どちらにも入口が無いとき・通路の無い区画（交差点・曲がり角）：草地を横切らずに、着いたことにする。
4. **駅のまわり。** 歩道に並べる人は、腕の無い側（T 字の向こう）には並べない。駅前広場・入場規制の列の立ち位置は、道路の区画に掛かる所では歩道・路側帯・入口の通路の上だけにする。

遠くの簡略な人（`lodcrowd.ts`）は v103 の `walkPos` のままで、歩道（路側帯）の帯の上にいる。歩道の幅は変えていないので位置は変わらない。

## 確かめたこと

### テスト（`tests/v104a_section.test.ts`、9 件）

- `kerbPlan`：幹線・二車線・その交差点は歩道あり、ふつうの生活道路は路側帯、駅のまわりの生活道路は歩道あり、曲がり角は両側が歩道ありのときだけ。
- 区画の境の両側で、腕の断面（歩道か路側帯か）が同じ。
- `roadBase` が描いた面を集め、区画の境の上の歩道（路側帯）の帯の高さを調べる：歩道ありの腕は 20cm、路側帯の腕は路面の高さ（平板の横腹が出ない）。
- 幹線と路側帯の生活道路の角：段差のある面は、隅切りの円弧の先 6m までで終わる。
- 人の足元（`frontage.ts` の `surfaceAt`。歩道の帯は `roadBase` と同じ決め方）：遠くの人と同じ `walkPos` の位置 10 万か所以上で、草地は 0、車道は交差点で渡るときだけ。建物に出入りする人の道筋は、歩道か入口の通路の上だけ。

### ゲームの中で数えた（`scripts/v104a-diag.mjs`・`scripts/v104a-count.ts`）

朝 8 時の駅前（真上の画と同じ所）で 12 秒、2 秒ごとに足元の面を数えた（延べの人数）。

| 人の種類 | 足元 | 直す前 | 直した後 |
|---|---|---|---|
| 精細な人（歩いている） | 草地 | 0 | 0 |
| 精細な人（建物に出入りしている） | 草地 | **683** | **0**（入口の通路 527・歩道 50） |
| 遠くの簡略な人（駅にあふれた人を含む） | 草地 | **116** | **0** |
| 駅の人だかり（精細） | 草地 | **144** | **0** |

車道の上にいるのは、交差点で横断歩道の位置を渡る人と、生活道路で向かいの入口へ道を渡る人だけ（直す前と同じくらいの数）。「敷地など」（駅前広場・ホーム）は道路の区画の外なので、ここでは数えていない。

### 画像（自分で見て確かめた）

- `goal-8am-before.jpg` / `goal-8am-after.jpg`：朝 8 時の駅前を真上から。後は、駅前の通りに歩道が区画をまたいで続き、交差点の角は縁石の円弧でつながる。人は歩道と入口の通路の上を歩き、草地に列は無い。
- `junction-oblique-*.jpg`・`junction-top-*.jpg`：駅から離れた、二車線の道と路側帯の生活道路の十字路を斜めと真上から。後は、二車線の道の歩道が角を回ってから、生活道路の側で斜めにすりつけて終わり、その先は路側帯と外側線が続く。
- `station-oblique-*.jpg`：駅の裏手の上から、駅前の通りと交差点を斜めに。

確かめていないこと：

- 夜・雨・品質「低」の見え方、実在の地図（保土ケ谷）は撮っていない。実在の地図の道路は線で描くので、今回の区画ごとの描き方は通らない（入口の通路も描かない）。
- 駅舎・駅前広場の敷地の中（`models.ts`・`landmarks.ts` が描く所）は変えていない。駅前広場の立ち位置が敷地の中の芝生に掛かるかは、敷地の絵の側で決まるので数えていない（数えたのは道路の区画の中だけ）。
- 性能は測っていない。増えたのは入口の通路の面（1 か所 2〜4 枚）と、すりつけの所の頂点が少しだけ。歩く人の計算は、着いたときに 1 回入口を調べるだけ。
