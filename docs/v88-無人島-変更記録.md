# v88 無人島（特別シナリオ）と、広げた土地の見た目 — 変更記録

## 1. 無人島（地形 `castaway`「無人島（特別シナリオ）」・開拓島）

### 仕組み
- **地形**（`src/sim/map.ts` の `castawayMap`）：四方を海に囲まれた島。中央に高さ 60m ほどの山と森（山頂は岩場）、東に低い峰、山から南の入り江へ流れる沢、西に湧水の池、まわりは砂浜。地図の縁はすべて海。国道・鉄道・橋・はじめの街はない。陸 約 5,500 区画（うち建てられる平地 約 3,900）。
- **解放**：はじめから選べる（当初は市長の経歴 Lv7 だったが、作者がすぐ遊べるよう Lv0 に変更）。タイトルの地形の選択にそのまま出る。今週の大会には出さない（`contestTerrain` は従来の 8 地形だけ）。
- **シード**：`seedForTerrain('castaway')` = 2,008,261,011（地形番号 8）。新しい地形が増えただけなので保存形式の版は上げていない。島専用の状態は保存しない（台風の欠航は既存の `modifiers` に入る）。
- **接続**：島で本土とつながっていないうちは、**操業中の桟橋・港（pier / port / fishPort / cruisePier）に面した道路**が市外への出入口（`isle.ts` の `shipGates` を `core.ts` の `roadInfo` の起点に足す）。通勤・来訪の経路の起点も桟橋になり、国道の通過交通はない。地図の端の国道の出入口（0,15）・（127,15）まで道路（橋）を通すと、ふつうの街と同じ接続になる。
- **はじめの状態**：人口 0・建物 0・道路 0・資金 11,700 万円（通常の 45%）。下水は浄化槽（2,000 世帯分まで不要）、ガスはプロパン（不足なし）、電気・水・通信の基礎の容量は 0。区域の編入はなし（島全体が村の区域）。チュートリアル（駅前の開発）は出さず、課題と初仕事で案内する。
- **転入の条件**：島では、水（井戸など）と電気（発電）がないと、はじめの 1 世帯も来ない（需要の下限を 4 世帯として水・電気の充足を見る。電気は 4 割未満で 0、10 割で満額）。
- **財政**：役場の基礎の費用と交付税の基礎の分は、人口に応じて 6%（0 人）〜100%（8,000 人）。国の**離島開拓の交付金 450 万円/月**（はじめの 10 年）と、離島振興の交付税の加算 ×1.3。**食べ物の船便の運賃**：島で採れない分 1 世帯あたり 0.6 万円/月（台風の欠航中は 1.8 倍）を「基礎行政費」に計上。
- **食料の自給率**：開拓の畑・漁船だまりの実効容量（作柄を掛ける）÷ 世帯数。課題と台風のできごとの説明に出す。
- **できごと（島だけ）**：
  - 台風で定期船が止まった（7〜9 月、桟橋か港がある島。2 か月、転入 2 割・船便の運賃 1.8 倍。ヘリで物資 900 万円 か 備蓄でしのぐ）
  - 発電機の燃料の船が遅れている（ディーゼル発電機があるとき。3 か月、電気の力 8 割。チャーター船 700 万円 か 節電）
- **開拓の段階**（`ISLE_STEPS`。今月の課題の先頭と、初仕事の先頭に出す）：
  1. 上陸：桟橋をつくる（報酬 800 万円）
  2. 桟橋から道を通す（300）
  3. 水：井戸か雨水タンク（400）
  4. 電気：発電機か太陽光（600）
  5. 住まい：開拓小屋（500）
  6. 食べ物：畑か漁船だまり（600）
  7. 通信と急病：無線中継塔と診療所（800）
  8. ごみを島で処理（800）
  9. 島を育てる：人口 3,000 人（5,000 万円・知名度 +4）。港・海水淡水化・観光・本土への橋は既存の施設で
- **オートプレイ**：人口 1,500 人までは島専用の手順（`autoplay.ts` の `islandTurn`：桟橋 → 道 → 水 → 電気 → 小屋 → 食べ物 → 無線塔・診療所 → 焼却炉、足りなければ道をのばす）。それ以降はふつうのオート。

### 遊び方の流れ
1. 南の入り江（はじめのカメラの位置）の水辺に桟橋を置く。
2. 桟橋の横から道路を内陸へのばす（桟橋に道路でつながった区画だけが使える）。
3. 道路沿いに井戸・雨水タンク（沢の近くなら簡易浄水施設）。
4. ディーゼル発電機（すぐ・高い）か太陽光パネルと蓄電池。
5. 開拓小屋を数棟。定期船で開拓者が来る（桟橋がないと誰も来ない）。
6. 畑・漁船だまりで自給率を上げ、船便の運賃を減らす。無線中継塔と診療所、小型焼却炉。
7. 人が増えたら住宅の用途を指定して民間の家を呼び、海水淡水化・港・海水浴場で観光、いつか本土へ橋。

### テスト（`tests/v88_isle.test.ts`）
- はじめは道路・建物・人がない。次の一手は桟橋で、課題と初仕事の先頭に出る。島の施設はふつうの街では置けない。
- 桟橋 → 道 → 井戸 2 → 太陽光 2 → 小屋 6 で 18 か月後に 24 世帯・62 人。次の段階は「食べ物」。
- 桟橋がないと、同じ道と家があっても 0 世帯。
- 20 年回して NaN・例外なし（古い施設は更新する前提。災害で施設が一気に古くなることがある）。
- オートプレイで 6 年回すと 85 人（15 棟）。

## 2. 広げた土地（v87 の 76 列目から東・68 行目から南）の見た目
- **田畑・草地・屋敷林・空き地**：`map.ts` の `extDeco`。3×2 区画の田畑の区割り（行ごとにずらす）を基本に、11 区画ほどの大きなまとまりで「田んぼの多い所」「草地の多い所」を分け、低い所ほど田んぼ。地形ごとに割合を変える（田園は田んぼ 5 割、都会は空き地と草地が多い など）。新しい印：6 畑（土とうね）・7 草地（野原）・8 屋敷林・雑木林の跡・9 空き地（田んぼは既存の 2 で、水を張った田とあぜを描く）。**見た目だけの印**なので、古いセーブの計算（建てられる土地・浸水・地価など）は変わらない。初期の街と v86 までの範囲には付けない。
- **地面の色のむら**：これまで 20m 角ごとの乱数で明暗を付けていたため、上空から市松模様に見えていた。なめらかな大小 2 つのむら（約 150m と 40m）に変更（地図全体の描画。地形のデータは変えていない）。
- **明るさの境目と黄色い線の原因**：地面の継ぎ目・チャンク・影・霞ではなく、**編入前の区域の暗幕（薄い黒の面）と、境目の黄色い柵**（`rebuildLock`）。はじめの区域は人のいる街区（旧 76×68 の北西）なので、全景ではそこだけ明るく、その縁に黄色い線が見えた。カメラが 1,600m より遠いと暗幕を 35% まで薄くし、柵を消す（近くでは今までどおり）。
- **見送り**：広げた土地の起伏・川や水路を増やす（標高や水面を変えると、古いセーブの建てられる土地・浸水の計算が変わるため）。新しく始めた街だけに効かせるには、シードの区別（既存の terrainV2 は 20 億以上で、v87 以降の新しい街もすでにそこに入っている）を新たに設ける必要があり、はじめの街の家並み（シードの乱数）も変わるので、作者に確認してから。

## 未検証・気になる点
- 本土への橋：地図の端の国道の出入口まで橋を通すとふつうの接続になる作りだが、実際に橋の道具でつなぐ操作はテストしていない。
- 財政の釣り合い：オートの 6 年で資金が 1.2 億 → 6.3 億に増えた（交付金が手厚い）。開拓を急ぐ人には余裕があるが、ためすぎになるなら交付金（`ISLE_GRANT`）か期間を減らす。
- 診療所は「誘致」の施設なので、島の小さな人口では来ないことがある（ヘリポートは市の直営で確実）。
- 桟橋のモデルは向きを持たない（どちらが海でも同じ形）。
- 島の地図で、車・人だかりの描画（scene.ts の通過交通の出入口）は国道を前提にしている所がある。画面で大きな破綻は見ていないが、細かくは確かめていない。
