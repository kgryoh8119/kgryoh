# v95 歩道と施設の人だかり 変更記録

作者の指摘：「歩道や車道の道路の表現が変だからちゃんとして」「学校の定員を超過しているなら、校庭や教室や学校の周りに人があふれる表現に。ほかの施設も」

## 1. 歩道と車道（`src/render/roadbase.ts` 新規、`roadkit.ts`、`scene.ts` の道路の区画の部分）

### 見つけたおかしな所（v94、`scripts/v95-road.mjs` の試験用の道路網で撮影）
- 交差点の区画は、その区画の等級の幅で描いていた。生活道路や 2 車線の区画に広い道が入ると、**交差点の中だけ広い道が細くなり**、歩道と縁石が段違いになった。
- 歩道・路面を 2.5m の升目で塗っていたため、幅の違う腕や区画の中心の正方形で**歩道の外の端が段々**になった。
- 交差点の角は直角（隅切りなし）。縁石は腕ごとの直線で、角で途切れたり、狭い腕の付け根で鉤型に折れた。
- 横断歩道は区画の幅（hw）から決まる位置で、横切る道の幅と関係がなく、**歩道の切り下げとつながらなかった**。外側線は交差点の中・横断歩道の上まで伸びていた。
- 曲がり角（L 字）の区画には縁石が無かった。T 字の突き当たり・行き止まりは別の部品の縁石で、歩道とずれた。

### 直したこと
- 区画を 4 つの象限に分け、象限ごとに「車道の端（縁石）」の折れ線を作り、そこから外へ **SIDEWALK_W（2.5m、従来の SW と同じ）** の帯を歩道にする。等級によらず歩道の幅は一定、区画の境で必ずつながる。
- 交差点の角は **隅切り（半径 CORNER_R = 3m の円弧）**。道幅の違う道どうしでも、それぞれの縁石の線を円弧でつなぐので、広い方の歩道が角を回り込む。
- 交差点の区画は **つながる道のうち一番広い道の幅と等級**で描く（交差点の中で国道が細くならない）。
- 直線の区画で両端の幅が違う（拡幅の始まりなど）ときは、区画の中で幅をなめらかに変える。
- 横断歩道は `xwRange(ah, perp)`：横切る道の半幅 + 1.5m（隅切りの円弧の途中）から、幹線 4m・その他 3m。横断歩道の両端の歩道は **切り下げ**（縁石を 2.5cm に下げ、歩道を傾ける）と **点字ブロック（黄）**。停止線は横断歩道の 1.2m 手前。外側線は停止線より手前で止める。
- 縁石は折れ線に沿って連続（立ち上がり・天端・L 字の側溝）。曲がり角の円弧にも縁石と側溝。行き止まりは丸めた端を歩道が回る。
- 段差のある歩道の道が生活道路（段差なし）とつながる腕では、歩道と縁石がその腕の先で路面の高さまで下りる。
- 生活道路は従来どおり段差なし、白線の外の路側帯（学校の近くは緑）を歩く場所として、隅切りの形で描く。
- 信号機の柱・横断歩道と止まれの標識は、角の歩道（`cornerSpot`）・横断歩道の先の歩道に立てる。

### 歩道の位置の定義（(a) 車・歩行者の担当へ）
- **変えていないもの**：歩道の幅 2.5m（scene の `SW`）、直線の区画の歩道は車道の端 `hw` から外へ 2.5m、歩道の高さ（路面 +0.1）。歩行者の位置の計算（`HW[road] + 1.25`）はそのまま歩道の中央に乗る。
- **変えたもの**：
  - 交差点の区画の車道の半幅は、つながる道の最大（例：2 車線の区画に国道が入る交差点は 7.5m）。scene の `hwAt` は従来どおりで、交差点の区画の中だけ広げる。
  - 交差点の角は円弧（角の歩道の内側の角が 3m の円弧で丸い）。
  - 横断歩道の位置：従来 `hw + 0.6`〜`hw + 0.6 + 3/4` → v95 は `roadbase.ts` の `xwRange(ah, perp)`（腕の中心から perp+1.5〜）。停止線は `xwRange` の終わり + 1.2m。車・人の「横断歩道の前で止まる」位置（scene の `HW + 2.4`・`HW + 5.4`）を合わせるときは `xwRange` を使ってください。

## 2. 施設の利用者の人だかり（`src/render/occupancy.ts` 新規、scene.ts の `rebuildLife` に呼び出し数行）
- `occupancyOf(s, b, hour)`：施設の混み具合（いる人数・利用÷定員・待つ人）。今は `b.used`・`b.effCap` と市の統計（待機児童、人口と医療の容量）から決める。住民一人ひとりの sim がつながったら、この関数の中身だけ差し替える。
- `crowdPlan(...)`：時刻と混み具合から、人の位置（立つ・その場で少し動く）と小物（仮設教室・窓の人影・救急車・ごみ収集車の列）を決める。人は既存の施設の人（`lifeP`、people.ts の人の形）に混ぜて描く。品質 low は 0.35 倍、mid は 0.7 倍。
- 学校：登校（7:24〜8:30）は校門の列と校庭、授業中は教室の窓の人影（定員比で 1 枚に 1〜3 人）と体育の 1 クラス、休み時間（10:15〜10:36、12:42〜13:24）は校庭いっぱい、下校。**定員超過**：校庭の密度が上がる、仮設教室（プレハブ、超過 35% から 2 階建て）、門の外の歩道まで子どもと見守りの大人。
- 保育園：園庭の子ども（午前・夕方）、朝夕の送り迎えの親子。待機児童（市全体を定員の割合で配分）が多いと門の前に親子の列。
- 病院・診療所：入口のまわりの人、超過なら入口の外に列（高齢者・車いす）、病院は救急車が並ぶ（超過ほど多く）。
- 公園・商業・行楽地：来訪者に応じた人。行楽地は休日らしい月（1・2・5・8 月など）に混み、入場待ちの列。駅は従来の乗客（crowdP）のまま（重ねない）。
- 役所・図書館・文化・福祉・体育館・プール：開いている時間に入口のまわり。ごみ処理場：搬入時間に収集車の列（ごみの量÷処理能力）。
- 時間の区切り（`occupancyPhase`）が変わると置き直す。
