# v98 住民の移動の描画 変更記録

作者の依頼：「人全員にちゃんと人生をつくって。学校に通ったり、仕事に向かったり、人数分ちゃんと表現して。駅を使ったり、車で通勤したり、行楽地に行ったり、全員を表現して。」

v95 で sim 側にできた住民一人ひとりの層（`src/sim/people.ts`）を、画面の車・歩行者・自転車・バス・駅の人・施設の人だかり・事故につないだ。
**sim の計算と保存形式は変えていない**（読むだけ）。新しいファイルは `src/render/residents.ts`（描画の側の住民の扱い）。

## 1. 車・歩行者・自転車・バス（`residents.ts` の `residentPlan`、`scene.ts` の `spawnAgents`・`resTick`）

- **だれを出すか**：見えている範囲（注視点から半径 24 区画）で、いま移動中の住民。
  - 平日の通勤・通学とその帰り：sim の口 `sampleTrips(s, hour, 500)` を時刻を少しずらして 3 回呼び、いまの位置（経路の進み具合の所）が見える範囲にある人を先に取る。
    足りない分は住民の一覧（`people(s)`）を 1 回なめて同じ決まり（出発・帰りの時刻と片道の時間）で補う。
  - 平日の昼（9〜17.5 時）：通勤・通学のない家の大人・高齢者の 3 割が買い物（休日の行き先が店ならその店、公園ならその公園で「散歩」、ほかは最寄りの店）、
    通院のある人の 4 回に 1 回が最寄りの病院・診療所へ。時刻は住民と日ごとのハッシュ。
  - 休日（描画の日を 7 日でめぐり、5・6 日目。`view.holiday` で固定できる）：住民の休日の過ごし方（`hol`・`holDest`・`holMode`）で、行楽地・公園・買い物・通院へ行って帰る。
    行楽地は 8.5〜11.5 時に出て 3〜7 時間、公園は 1〜3 時間。休日は平日の通勤・通学は出さない。
  - 夜は移動する住民がほとんどいないので、ほとんど出ない（業務の車が少し走る）。
- **どの手段で**：住民の手段のまま。徒歩は歩道を歩く人、自転車はママチャリ（働く人の 3 割はスポーツ車）、車は乗用車、バスはその辺りでバスに乗っている住民 25 人で路線バス 1 台。
  電車の人は駅まで（駅までの手段で）。見た目は役割から（小学生・中学生・働く人・買い物の人・高齢者、休日は普段着、行楽地は観光の服）。
- **どこへ**：その住民の行き先の道路の区画へ向かう。区画ごとに次の区画を、行き先からの道のりの距離（道路の網の幅優先。徒歩は高速道路を通らない。1 コマに 4 本まで作り、道路が変わるまで使い回す）で選ぶ。
  まだ距離が無いときは近づく向き。着いたら、人は建物に入り（v95 の入る動き）、車は駐車して、見えている範囲のまだ画面にいない住民に入れ替わる（家から出てくる）。
- **数**：見えている範囲で移動中の住民の数（手段ごと）どおりに描く。上限は性能のため（車 250・自転車 80・人 400 を品質の倍率で。軽い表示ではさらに少ない）。
  今の「交通量に比例する台数」の決め方は置き換えた。5 秒に 1 回、住民の移動を作り直して、足りなければ家から出てくる人・車を足し、多すぎれば人は建物に入って消え、車は遠い順に消える
  （全部を置き直さないので、時刻が進んでも画面は飛ばない）。
- **ほかの車**：業務の車（トラック・タクシー・配達。住民の車の 1 割ほど）と、混んでいる道の列（v87。列の車にもその時間に車で動いている住民を割り当て、足りなければ「市外から来た車」）。
- **押すと紹介**：人・車を押すと、押した所の近くにその住民の紹介が出る（8 秒、押すと消える）。架空の名前（同じ建物の住民は同じ名字になりやすい）・年齢・役割、
  住まい（地区と建物）・世帯の種類、いまの用事と行き先、手段（電車の人は駅までの手段も）。
  例：「石井 凛さん（33歳・働く人）｜住まい：駅前の集合住宅・単身世帯｜いま：市外へ通勤（電車）→鉄道駅（駅前）｜手段：電車（駅まで徒歩）」
- v95 の、車・人が重ならない・坂に沿う・歩道を歩く、はそのまま（動きの処理は変えず、次の区画の選び方だけを差し替えた）。

## 2. 駅（`scene.ts` の `stCrowdRes`、`residents.ts` の `stationFlow`）

- 駅ごとの、いまの時刻の 1 時間あたりの乗車を住民から数える（電車で通う人が駅に着く時刻 = 出発 + 駅までの時間 が前後 15 分に入る人）。
  休日は、休日の手段が電車の人が 9〜11 時・16〜18 時に。
- 混雑率 = 40 + 100 × 乗車（1 時間）÷（1350 人 × 輸送力の倍率）。1350 人は sim の目安「1 日 9000 人の乗降で 100%」の朝のピーク 1 時間（乗車は乗降の半分、ピークはその 3 割）。
  輸送力の倍率（増発・複線・車両基地）は sim の `stationStats` の混雑率と乗降から逆算した。この混雑率を v87〜v88 の人だかり（ホーム・詰まり・改札前・入場規制・歩道）にそのまま渡す。
  時刻は住民の値に入っているので、今までの「朝夕の目安」は掛けない。住民がいない街は今までの値。
- 朝の乗車の合計（v95 の `peopleStats.boardings`）は検査用に `view.stInfo()` で見られる。

## 3. 施設の人だかり（`occupancy.ts` の `occupancyOf`、`residents.ts` の `presentAt`）

- いまその施設にいる住民の数を、住民の居場所から出す：平日は、通学・通勤の人は着いてから帰りの出発まで行き先に、昼の買い物・通院・散歩の人は用事の間（1 と同じ決まり）。
  休日は休日の行き先に滞在の間と、店・行楽地・病院で働く人の 6 割。15 分ごとに作り直す。
- 学校・保育の混み具合（ratio）は v95 の在籍（`enroll`）÷ 定員。行楽地は市外からの来訪を今までの目安の半分だけ足す（住民だけでは観光地が空になるため）。
  休日の入場待ちの列は、描画の休日にも出る。ごみ処理の待ちは今まで通り。

## 4. 事故（`main.ts`、`scene.ts` の `incVictim`、`residents.ts` の `incidentRateK`）

- `view.onIncident` を sim の `recordIncident` につないだ（main.ts）。sim は「見えた分」として数えるだけで、件数の本体（sim の確率）には足さない。病院で亡くなった追加の知らせ（fatal）は数えない。
- 描画の事故の頻度：`view.incidentRate` = 注視点のまわり 7×7 区画の道路の、sim の `incidentRate`（場所・時間帯の 1 時間あたりの期待件数）の平均 ÷ 街全体の道路の平均（0.1〜5 倍）。
  衝突・違反は車、歩行者は歩行者＋自転車の値。時間帯は sim の値に入っているので、今までの時間帯の目安は掛けない（火災・鉄道は sim の区画の値が小さすぎるので、時間帯の目安だけ）。
- 事故に遭った人・車は住民：歩行者の事故のけが人は、近く（40m 以内）を歩いていた住民（画面から消えて倒れた人になる）、いなければこの辺りを歩いて移動中の住民。
  車の事故は、その車を運転していた住民。搬送の知らせに「（名前さん・年齢・地区在住）」が付き、倒れた人を押すとけが人の紹介が出る。
